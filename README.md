# Malcolm Lismore Photography

A professional responsive photography portfolio website designed for Malcolm Lismore, a freelance photographer based on the North West coast of Scotland.

## Project Overview

Malcolm Lismore is passionate about the natural world and specialises in photography of the rugged Scottish landscape, wildlife and coastal birds.

The website also promotes his professional photography services for:

- Weddings
- Portraits
- Special Events

The website has been designed to provide a visually engaging photography experience while making it easy for potential clients to explore Malcolm's work and make enquiries.

## Features

- Responsive home page
- Professional navigation
- About Malcolm page
- Photography portfolio
- Photography category galleries
- Landscape photography
- Wildlife photography
- Coastal bird photography
- Wedding photography
- Portrait photography
- Event photography
- Services information
- Pricing information
- Enquiry form
- Responsive design
- Image gallery interactions
- Image lightbox
- Mobile-friendly navigation
- Client-side form interface
