# 📸 Malcolm Lismore Photography

A modern, responsive photography portfolio website designed for Malcolm Lismore, a photographer based on the North West coast of Scotland. The website showcases photography work, introduces the photographer's services, presents pricing information, and provides an enquiry interface for potential clients.

## 🌐 Live Demo

**Website:** https://kavindhya-gothmini.github.io/malcolm-lismore-photography/index.html

## 📖 About the Project

The Malcolm Lismore Photography website was developed as a frontend web development project to create a professional online presence for a photographer specializing in landscapes, wildlife, coastal birds, weddings, portraits, and events.

The website focuses on attractive visual presentation, intuitive navigation, responsive layouts, and an accessible browsing experience across different devices.

## Features

- Responsive home page

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layouts, and responsive design.

- **Bootstrap 5.3.3** — Responsive layout and UI components.
- **Bootstrap Icons 1.11.3** — Interface icons.
- **Google Fonts** — Inter and Playfair typography.
- **GitHub Pages** — Website hosting.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/kavindhya-gothmini/malcolm-lismore-photography.git
   ```

2. Navigate to the project folder:

   ```bash
   cd malcolm-lismore-photography
   ```

3. Open `index.html` in your web browser, or use the **Live Server** extension in Visual Studio Code.

No backend installation is required for the static frontend website.
